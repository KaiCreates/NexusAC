Connect a server

The anti-cheat talks to this website outbound only. Nothing is port-forwarded, and the resource exposes no HTTP handler of its own.

1 · Get an API key

Create an account, open the dashboard, press Add server and name it. The key is shown once — the site stores only a hash of it.

2 · Put it in server.cfg

Both lines must come before ensure NexusAC.

set nexus_web_url "{{ app_url }}"
set nexus_web_token "your-43-character-key"

ensure NexusAC
{{ ui.icon('lock', 17) }} The resource accepts an https:// origin, or http:// only when it is localhost. Deploy to Vercel and use that HTTPS URL for a real server.

3 · Restart and check

restart NexusAC

The server console tells you which state it is in.

Console lineMeaning
(nothing about Web) Connected. It polls every few seconds.
[NexusAC Web] Not configured. One of the two convars is missing or empty. In-game protection is unaffected.
[NexusAC Web] Invalid URL or key. The URL is not HTTPS (or localhost), or the key is not exactly 43 characters.
Sync failed (HTTP 401) The key does not match. Rotate it on the dashboard and paste the new one.
Sync failed (HTTP 400) Usually the machine clock: the two sides must agree within 90 seconds.
Sync failed (HTTP 409) A replayed or out-of-order snapshot. Restart the resource for a fresh session.

Screenshots

Evidence screenshots need the Nexus-Screens resource running alongside NexusAC — it provides the server-side requestClientScreenshot export. Without it, cases still arrive, with their screenshot status recorded as unavailable.

What the website can and cannot do

CanCannot
Kick, ban, unban, freeze, request a screenshot, change a whitelisted setting, change a detector's mode. Run arbitrary code, read a webhook URL, set a config path that is not in the schema, or act while the server is offline.
{{ ui.icon('shield-check', 17) }} Every command expires after 60 seconds and carries a receipt id. If the connection drops mid-execution, the retry returns the previous result rather than running the action twice.
